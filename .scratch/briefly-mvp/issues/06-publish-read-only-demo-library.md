# 06 — Publish the read-only Demo Library

**What to build:** Recruiters can inspect a curated, useful public Demo Library while the owner’s Personal Workspace and Gemini-powered generation workflow remain private.

**Blocked by:** 03 — Generate and open a source-faithful Brief.

**Status:** ready-for-agent

- [ ] The public Demo Library contains three to five seeded English Briefs from genuinely public, source-linked YouTube videos.
- [ ] Each public Brief is clearly labelled as generated and includes the source-and-safety notice.
- [ ] Public routes are read-only: they expose neither the live URL-submission workflow nor any personal Briefs.
- [ ] Application-boundary tests prove anonymous public reading, seeded content visibility, and absence of private/generation behavior.
